# Football Quiz

A small, menu-driven Java quiz covering football rules, facts about players and teams, 
and football competitions. Players enter their name, choose a quiz topic, 
and earn points for correct answers. A ranking shows how each player scored.

## Author

Alexa

## Project constraints

The project uses structured programming in Java. 
Quiz questions and player scores are represented with records or 
simple classes and stored in arrays. Methods, loops, and conditionals handle 
the quiz flow, scoring, and ranking. The implementation avoids abstractions, 
inheritance, Collections, and other higher-level Java features.

## Getting started

Open the project in a Java IDE and run its main class. 
Enter a player name, choose a topic, answer the questions, 
and check the ranking after the quiz.
