# Football Quiz Features

1. Enter a player name before starting a quiz.
2. Choose from quiz topics covering football rules, player facts, teams, and competitions.
3. Ask multiple-choice questions about the selected topic.
4. Check answers and award points for correct responses.
5. Show the correct answer when a response is incorrect.
6. Display the player's final score and number of correct answers.
7. Show a ranking of quiz players sorted from highest to lowest score.
8. Validate player names, menu choices, and answer input.
